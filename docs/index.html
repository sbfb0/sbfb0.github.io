SBFB Documentation

Welcome to the official documentation for Standard Based Frontend and Backend (SBFB). SBFB is a unified scripting language that compiles HTML, JavaScript, Python, and agentic AI tools into a single, cohesive syntax.

Note: You can test all of these commands live using the SBFB Type Studio!

Getting Started

Every SBFB script must begin and end with the core initialization tags.

start:SBFB
// Your code goes here
<end:SBFB>

Environments

SBFB allows you to declare the environment your code is running in:

  • frontend - Optimizes for web output.
  • backend - Optimizes for server/logic output.
  • idk - Auto-detect the environment.
